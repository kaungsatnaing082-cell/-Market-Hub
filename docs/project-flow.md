# Krest Center Part 1 Flow

Public visitor
→ Home
→ Search / scroll products and centers
→ Register or login when identity is required

Seller registration
→ Seller account
→ Center request is handled in Part 2
→ Admin receives request
→ Approve or reject
→ Approved request creates an active center

Buyer registration
→ Buyer account
→ Shopping dashboard is Part 3

Admin
→ Dedicated admin login
→ JWT-protected admin dashboard
→ Center requests / reports / centers / sellers / buyers / finance / warnings / settings
